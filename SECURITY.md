# Sécurité

## Signaler une faille

Ne publie pas de faille dans une issue. Utilise le [signalement privé de GitHub](https://github.com/banedPowell/torgas/security/advisories/new). Je réponds sous 7 jours.

## Versions suivies

Le projet est en phase prototype : seule la branche `main` reçoit des correctifs.

## Principes

- Les fichiers et le texte des livres restent sur tes appareils ; aucun serveur ne les reçoit.
- Notes, positions et historique sauvegardés sur le serveur sont chiffrés de bout en bout (à partir du MVP).
- Aucun contournement de DRM.
